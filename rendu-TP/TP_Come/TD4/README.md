# TD04 - Branches + Merge - Côme Leblois

## Objectif
Ne plus développer directement sur `main` : une fonctionnalité = une branche.

## Ce que j'ai fait
- Création d'une branche de fonctionnalité à partir d'un `main` propre.
- Fonctionnalité : afficher la première et la dernière date d'observation.
- Commit : `bcd9cdd feat: display first and last observation dates`.
- Comparaison de la branche avec `main`, puis merge dans `main` local.
- Inspection du graphe Git (`git log --oneline --graph`).
